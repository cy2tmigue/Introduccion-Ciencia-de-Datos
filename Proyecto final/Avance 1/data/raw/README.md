# Datos fuente

Esta carpeta recibe los CSV originales descargados desde la carpeta data-csv del repositorio jfjelstul/worldcup.

No es necesario descargar los archivos manualmente. Ejecuta:

~~~bash
python src/download_data.py
~~~

El script descarga los 11 CSV utilizados por este avance:

- awards.csv
- award_winners.csv
- confederations.csv
- goals.csv
- matches.csv
- players.csv
- player_appearances.csv
- squads.csv
- stadiums.csv
- teams.csv
- tournaments.csv

Fuente: Joshua C. Fjelstul, Ph.D., Fjelstul World Cup Database.
